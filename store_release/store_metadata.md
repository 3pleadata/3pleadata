## 3. App Store Privacy & Data Safety Declarations

### Apple App Store Privacy Nutrition Labels:
1. **Financial Info:**
   - *Payment Info & Transaction History*: Used for App Functionality (processing bills, transfers, flight bookings). Linked to user account.
2. **Contact Info:**
   - *Email, Name, Phone Number*: Used for Account Creation, Fraud Prevention, Customer Support. Linked to user account.
3. **Identifiers:**
   - *User ID / Device ID*: Used for Biometric authentication tokens, Push notifications. Not used for 3rd-party tracking.
4. **Camera:**
   - *Camera access*: Used solely when scanning QR codes for peer-to-peer transfers or invoice barcodes. Not stored or shared.

### Google Play Data Safety Form Answers:
- **Does your app collect or share user data?** Yes.
- **Is all user data encrypted in transit?** Yes (Enforced TLS 1.3 via Network Security Config).
- **Do you provide a way for users to request data deletion?** Yes. (Available directly inside the application under Settings > Legal & Security > Interactive Account Deletion Tool).
- **Data Types Collected:**
  - *Personal Info*: Name, Email, Phone number (for KYC and login).
  - *Financial Info*: In-app purchase history, wallet balances, transaction records.
  - *Device or other IDs*: Firebase Cloud Messaging token for push notifications.
